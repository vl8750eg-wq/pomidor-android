# Pomidor для Android 🍅

Фокус-таймер (помодоро) для телефона и планшета. Порт десктопного Pomidor.

## Что внутри

- Фокус / короткий отдых / большой перерыв, сет из 4 помидоров
- Автостарт отдыха и фокуса, звук, счётчики за день (🔥)
- **Заставка на весь экран поверх других приложений** в конце помидора и перерыва:
  - после помидора — красная вуаль 30% + красный текст
  - после перерыва — зелёная вуаль 30% + зелёный текст
- Работает в фоне (foreground-сервис), будит экран
- На планшете — двухколоночный layout, на телефоне — одноколоночный

## Как получить APK

APK собирается сам через GitHub Actions:

1. Обычный пуш — артефакт `pomidor-debug-apk` во вкладке Actions.
2. Тег `v1.0` и т.п. — APK прикладывается к Release.

Установка: скачай `app-debug.apk` на телефон и открой (разреши установку из неизвестных источников).

## Разрешения (зачем)

- `POST_NOTIFICATIONS` — уведомление с таймером и запуск заставки.
- `USE_FULL_SCREEN_INTENT` — заставка поверх других приложений.
- `FOREGROUND_SERVICE_SPECIAL_USE` — отсчёт в фоне.
- `VIBRATE` — вибрация вместе с сигналом.

## Сборка локально

Нужны Android Studio + JDK 17. Открыть папку проекта, дождаться sync, Run.

## Структура

- `MainActivity.kt` — главный экран (Compose, адаптивный).
- `TimerService.kt` — foreground-сервис: отсчёт, уведомления, full-screen intent.
- `AlarmActivity.kt` — полноэкранная заставка поверх приложений.
- `Prefs.kt` — настройки и статистика (SharedPreferences).
